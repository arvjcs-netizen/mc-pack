# Minecraft Resource Pack — Java 1.8.9

This repo is a Minecraft **Java Edition 1.8.9** resource pack.

## Layout
- `pack/` is the pack root. Everything inside it goes into the zip.
  - `pack/pack.mcmeta` — `pack_format` MUST stay `1` (1.8.x).
  - `pack/pack.png` — 128x128 pack icon.
  - `pack/assets/minecraft/textures/...` — textures.
- `packs/tidal/` — a second pack, "Tidal [16x]", 100% original and fully GENERATED by
  `tools/tidal/generate.py`. Modules share palettes/shapes in lib.py: blocks.py + decor.py (blocks),
  items.py + extra_items.py (items), armor.py, anim.py (water/lava/fire/portal/ore twinkle), gui.py (HUD,
  hotbar, glint), screens.py (container/menu GUIs), entities.py (mobs, chests, banners), world.py (sky,
  particles, font, colormaps, map, paintings, misc). It covers every 1.8.9 texture except font/unicode_page_*.
  Never hand-edit files in `packs/tidal/`; change the generator and re-run it (it wipes the folder's contents).
  Families must stay consistent: wool/clay/glass/dyes = one pattern per family recolored with `DYES`;
  swords/tools = one shape recolored with `MATERIALS`; armor = one mask/layout per piece; doors, saplings,
  records, minecarts, horse armor, crops = one shape each.
  The vanilla 1.8.9 jar is read ONLY for geometry (`lib.layout_mask` / `layout_gray`: which pixels a model
  samples, where GUI slots sit). Never copy its pixels or colors.
- `packs/mypack_gradient/` — "MyPack Gradient", a complete standalone pack GENERATED by
  `tools/make_gradient_pack.py`: MyPack with all diamond textures + the fireball recolored to the bow's animated
  violet -> cyan gradient pulse (worn/horse armor pulse via OptiFine `mcpatcher/anim`, since vanilla can't
  animate entity textures). Only those files, pack.mcmeta and `mcpatcher/anim/` are real copies; untouched folders are
  junctions to `pack/` and other files are hard links to `pack/`'s files, so MyPack edits show up live.
  Never edit files inside it: a hard-linked file IS MyPack's file. Never delete it with rmtree-style tools that
  follow junctions; the script's `wipe()` is safe. Re-run the script when MyPack's diamond/fireball textures
  change or a file is added to items/, blocks/, models/armor/ or entity/horse/armor/.
  Borrowed textures inside it follow the CREDITS.md / personal-use rules.
- `build.py` — zips a pack into `dist/<name>.zip` (`--pack mypack|tidal|gradient`, default mypack).
  `--install` copies the zip into `.minecraft/resourcepacks`; `--link` links the folder there instead.
- `tools/` — put texture-generation scripts here (Python + Pillow).

## 1.8.9 rules (important — newer versions differ)
- Folder names are PLURAL: `textures/blocks/`, `textures/items/` (not `block`/`item`, which is 1.13+).
- Use 1.8 file names, e.g. `blocks/grass_top.png`, `blocks/stone.png`, `items/diamond_sword.png`,
  `blocks/log_oak.png`, `blocks/planks_oak.png`, `items/apple.png`. Do not use 1.13+ names
  like `oak_log.png` or `grass_block_top.png`.
- Armor: `textures/models/armor/diamond_layer_1.png` and `_layer_2.png` (64x32).
- GUI: `textures/gui/widgets.png` (hotbar/buttons), `textures/gui/icons.png` (hearts, hunger, crosshair).
- Textures are PNG, square power-of-two sizes (16, 32, 64, 128...). Keep sizes consistent within the pack.
- Grayscale textures like `grass_top.png` and leaves are tinted by biome colormaps in-game.
- Animated textures: a vertical strip of frames plus a `<name>.png.mcmeta` file, e.g.
  `{"animation": {"frametime": 2}}`.
- Item model overrides go in `assets/minecraft/models/item/*.json` (1.8 model format).
- OptiFine features (CTM, custom sky) live under `assets/minecraft/mcpatcher/`.

## Workflow
1. Generate or edit textures (scripts in `tools/`, output into `pack/assets/...`).
2. The user plays with the linked folder pack `MyPack` (`python build.py --link`, already set up):
   `.minecraft/resourcepacks/MyPack` is a junction to `pack/`, so edits are live — just press F3+T.
   Don't overwrite `MyPack.zip` with `--install` while the game is running; 1.8.9 keeps the zip open
   and stops reading it until a restart. Use `python build.py` (no flag) to make a zip for sharing.
3. In Minecraft (Lunar Client 1.8.9), press F3+T to reload resources.

## Content rules
- Textures may be taken from other packs the user has downloaded, for personal use. Record every
  borrowed texture and its source/author in `CREDITS.md`. Before this pack is shared or uploaded
  publicly, borrowed textures need the original author's permission (or must be replaced).
- Do not copy Mojang's vanilla texture files into the pack.
- Delete `.gitkeep` files freely; the build skips them anyway.
